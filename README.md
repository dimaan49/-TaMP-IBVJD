В нашем репозиторию ветка main является основной, в неё заливаются только проверенные и утвержденные изменения, которые будут работать у всех. Ветки Server и Client будут запускать приложение клиента и сервера, но не факт, что будут работать вместе. Ветки beta_Client и beta_Server содержат неутвержденные изменения приложений клиента и сервера, которые дорабатываются до рабочей версии и отправляются в ветки Server и Client. Documents является обособленной веткой. В ней хранятся изображения, диаграммы, текстовые файлы вроде этого и файлы другого рода которые не имеют прямого отношения к написанию кода.
